# Vidspark頁面設計大師智能體創建指南

## 概述

本文檔旨在創建一個專門為Vidspark項目設計頁面的智能體系統，該智能體能夠理解需求、提供解決方案並修改相關代碼，確保所有頁面符合統一的設計標準和用戶體驗要求。

## 設計理念

### 核心原則
1. **簡潔明了** - 參照iOS設計風格，乾淨簡單

## 主題管理系統

### 主題類型
1. **靜態頁面主題**
   - 適用於登陸、註冊、價格等頁面
   - 保持品牌一致性
   - 明亮友好的視覺風格

2. **控制台主題**
   - 適用於儀表板、管理界面
   - 支持深色/淺色切換
   - 專業的數據展示風格

### 主題切換功能
1. **自動檢測**
   - 根據頁面路徑自動選擇主題類型
   - 支持系統偏好檢測
   - 記住用戶選擇

2. **手動切換**
   - VThemeToggle組件
   - 快捷鍵支持
   - 平滑過渡動畫

### 技術實現
1. **CSS變量系統**
   - 動態主題色彩
   - 響應式適配
   - 無障礙支持

2. **Vue組合式函數**
   - useTheme(): 完整主題管理
   - useSimpleTheme(): 簡化版本
   - 響應式狀態管理

#### 使用示例
1. **基本使用**
   ```vue
   <script setup>
   import { useTheme } from '@/composables/useTheme'
   
   const { isDark, toggle, themeClasses } = useTheme()
   </script>
   
   <template>
     <div :class="themeClasses">
       <VThemeToggle @toggle="toggle" />
     </div>
   </template>
   ```

2. **完整示例**
   - 參考 `src/examples/ThemeExample.vue`
   - 展示所有主題功能
   - 包含頁面類型檢測和配色展示
