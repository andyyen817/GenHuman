🔧 Zeabur環境變量檢查工具

目的：檢查PHP配置是否反映了Zeabur環境變量設置

📋 使用說明

  1. 點擊"檢查當前配置"按鈕
  2. 對比實際值與期望值
  3. 如果不匹配，請檢查Zeabur環境變量設置
  4. 設置完環境變量後，重新部署容器

⚙️ Zeabur環境變量設置指南

步驟1：進入Zeabur控制台

1. 訪問 Zeabur控制台

2. 選擇您的項目：genhuman-digital-human

3. 點擊 環境變量 標籤

步驟2：添加以下環境變量

PHP_UPLOAD_MAX_FILESIZE=1000M
PHP_POST_MAX_SIZE=1100M
PHP_MEMORY_LIMIT=2048M
PHP_MAX_EXECUTION_TIME=1800
PHP_MAX_INPUT_TIME=1800
PHP_MAX_INPUT_VARS=10000

步驟3：重新部署

1. 點擊 重新部署 按鈕

2. 等待部署完成（約1-2分鐘）

3. 重新運行此檢查工具驗證
